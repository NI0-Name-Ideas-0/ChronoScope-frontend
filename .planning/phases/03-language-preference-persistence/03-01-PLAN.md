    - inject(TranslocoService), inject(Api), inject(PLATFORM_ID)

      2. Call translocoService.setActiveLang(lang)
      3. Write LOCALE_MAP[lang] to localStorage
      4. Fire api.invoke(updateSettings, { body: { language: LOCALE_MAP[lang] } }) — non-blocking (no await needed, but catch errors with .catch for logging)
