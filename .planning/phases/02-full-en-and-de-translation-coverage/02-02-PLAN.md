<objective>
Create an automated verification script that extracts all transloco key usages from templates and services, cross-references them against en.json and de.json, and reports any gaps. Fix any missing translations found.

Purpose: Ensures zero untranslated keys remain visible to users. Provides a repeatable verification tool for future translation work.

Output: Passing verification script confirming 100% translation coverage, plus any gap fixes applied to en.json/de.json.
</objective>

<task id="02-02-1">
<objective>Create a verification script that checks translation completeness by extracting keys from templates and cross-referencing with JSON files</objective>
<read_first>
- public/i18n/en.json (current key structure to understand the format)
- src/app/components/navbar/navbar.html (example of transloco pipe usage pattern)
- src/app/components/task-modal/task-modal.html (example of transloco pipe in forms)
- src/services/task.service.ts (example of notification calls that should use translate service)
- src/app/interceptors/error.interceptor.ts (notification calls in interceptor)
</read_first>
<action>
Create scripts/verify-translations.js — a Node.js script (no dependencies beyond fs, path, and glob via recursive readdir) that:

1. EXTRACT KEYS FROM TEMPLATES: Recursively scan src/**/*.html files for transloco pipe patterns. Match these regex patterns:
   - `'KEY' | transloco` (single quotes around key, pipe to transloco)
   - `"KEY" | transloco` (double quotes)
   - `{{ 'KEY' | transloco }}` (interpolation)
   - `[attr]="'KEY' | transloco"` (attribute binding)
   Collect all unique KEY values into a Set called `usedKeys`.

2. EXTRACT KEYS FROM TS FILES: Scan src/**/*.ts files for TranslocoService usage patterns:
   - `translate('KEY')` or `translate("KEY")`
   - `selectTranslate('KEY')` or `selectTranslate("KEY")`
   Add these to the `usedKeys` set.

3. LOAD JSON FILES: Read public/i18n/en.json and public/i18n/de.json, extract all top-level keys into sets `enKeys` and `deKeys`.

4. CROSS-REFERENCE AND REPORT:
   - Keys used in templates/TS but missing from en.json → report as "MISSING IN EN"
   - Keys used in templates/TS but missing from de.json → report as "MISSING IN DE"
   - Keys in en.json but not in de.json → report as "EN-ONLY (no DE translation)"
   - Keys in de.json but not in en.json → report as "DE-ONLY (no EN translation)"
   - Keys in JSON files but never referenced in code → report as "UNUSED" (warning only, not error)
   - Empty string values in either file → report as "EMPTY VALUE"

5. EXIT CODE: Exit 0 if zero MISSING/EN-ONLY/DE-ONLY/EMPTY errors. Exit 1 if any errors found. Warnings (UNUSED) do not fail the check.

6. OUTPUT FORMAT: Print summary counts at the end, then detailed lists per category.

Make the script runnable via: `node scripts/verify-translations.js`
</action>
<acceptance_criteria>
- scripts/verify-translations.js exists and runs without error via `node scripts/verify-translations.js`
- Script scans all .html files in src/ for transloco pipe patterns
- Script scans all .ts files in src/ for TranslocoService translate/selectTranslate calls
- Script loads both en.json and de.json and compares key sets
- Script exits with code 0 when all keys are covered, code 1 when gaps exist
- Script reports: MISSING IN EN, MISSING IN DE, EN-ONLY, DE-ONLY, EMPTY VALUE categories
</acceptance_criteria>
</task>

<task id="02-02-2">
<objective>Run the verification script and fix any translation gaps found</objective>
<read_first>
- scripts/verify-translations.js (the script just created — understand its output format)
- public/i18n/en.json (file to fix if gaps found)
- public/i18n/de.json (file to fix if gaps found)
</read_first>
<action>
Run `node scripts/verify-translations.js` and analyze the output.

For each gap reported:

MISSING IN EN: Add the key to en.json with an appropriate English value derived from the key name (e.g., TASK_DELETE_CONFIRM → "Are you sure you want to delete this task?").

MISSING IN DE: Add the key to de.json with a natural informal German translation. Apply D-01 rules: use "du" tone, natural phrasing, not literal.

EN-ONLY: Add the German translation to de.json following the same D-01 rules.

DE-ONLY: Add the English translation to en.json.

EMPTY VALUE: Fill in the appropriate translation value for the language file where the empty string appears.

After all fixes, re-run `node scripts/verify-translations.js` and confirm exit code 0.

Additionally, verify the app builds successfully with `npx ng build --configuration=production` (or the project's build command) to confirm no broken template references.
</action>
