  <action>
Per D-05, modify showChronoErrorToast to resolve a localized title before passing to NotificationService. The function already receives translocoService (from Phase 1 wiring).

Replace the body of showChronoErrorToast with this logic:

1. Keep the existing status === 0 guard (connection error) at the top — it already uses translated strings from Phase 1. Leave it unchanged.

2. After the connection error guard, resolve the localized title:
   - If chronoError.errorCode is defined, set localizedTitle = translocoService.translate('ERROR_TITLE_' + chronoError.errorCode)
   - Else if chronoError.status >= 500, set localizedTitle = translocoService.translate('ERROR_FALLBACK_SERVER')
   - Else if chronoError.status === 404, set localizedTitle = translocoService.translate('ERROR_FALLBACK_NOT_FOUND')
   - Else if chronoError.status === 403, set localizedTitle = translocoService.translate('ERROR_FALLBACK_FORBIDDEN')
   - Else if chronoError.status === 401, set localizedTitle = translocoService.translate('ERROR_FALLBACK_UNAUTHORIZED')
   - Else if chronoError.status >= 400, set localizedTitle = translocoService.translate('ERROR_FALLBACK_REQUEST')
   - Else set localizedTitle = translocoService.translate('ERROR_FALLBACK_GENERIC')

3. Resolve the message body: use chronoError.message as-is (this is already the raw backend detail or fallback from ChronoscopeError constructor). Per D-04, the raw detail stays untranslated. However, if chronoError.message equals the hardcoded fallback strings "An unexpected error occurred" or matches pattern "Request failed: *", translate with ERROR_FALLBACK_MESSAGE instead, per D-07. Simplest approach: if chronoError.errorCode is undefined AND chronoError.detail is undefined (meaning no ProblemDetail body was present), use translocoService.translate('ERROR_FALLBACK_MESSAGE') as the message. Otherwise use chronoError.message.

4. Call notificationService.error(resolvedMessage, { title: localizedTitle, fieldErrors: chronoError.fieldErrors }).

Per D-06, fieldErrors pass through unchanged — field names stay as technical identifiers (ERR-03 satisfied).
Per D-04, localizedTitle IS the header (ERR-01 + ERR-02 satisfied by the same string).
Per D-08, no backend changes (BE-01 already satisfied).

Do NOT modify chronoscope-error.model.ts — the model stays pure with no DI dependency. The ERROR_CODE_TITLES map remains as a non-i18n fallback for any consumers outside the interceptor.
