<action>
For list-view component:
1. Add TranslocoPipe and TranslocoService to imports/injections in list-view.ts
2. Import TranslocoPipe in the component imports array
3. Inject TranslocoService and use it to make filter labels reactive: change the filters array labels to use translation keys. Since filter labels are rendered in template via {{ filter.label }}, change to store keys and pipe them in template: {{ filter.label | transloco }}. Update filters array values from { label: 'All', value: 'all' } to { label: 'LIST_FILTER_ALL', value: 'all' } etc.
4. In list-view.html:
   - Stat titles "Overall" → {{ 'LIST_STAT_OVERALL' | transloco }}
   - Stat title "Open" → {{ 'LIST_STAT_OPEN' | transloco }}
   - Stat title "Done" → {{ 'LIST_STAT_DONE' | transloco }}
   - "No tasks found" → {{ 'LIST_NO_TASKS' | transloco }}
   - "DueDate:" → {{ 'LIST_DUE_DATE' | transloco }}
   - "Progress" → {{ 'LIST_PROGRESS' | transloco }}
   - title "Collapse"/"Expand" → [title]="isExpanded(task) ? ('LIST_COLLAPSE' | transloco) : ('LIST_EXPAND' | transloco)"
   - title "Mark as open"/"Mark as done" → [title]="task.isFinished ? ('LIST_MARK_OPEN' | transloco) : ('LIST_MARK_DONE' | transloco)"
   - Similarly for scope mark done titles
   - title "Delete" → [title]="'LIST_DELETE' | transloco"
   - "Done" badge → {{ 'LIST_DONE_BADGE' | transloco }}
   - Filter button labels: {{ filter.label | transloco }} (since labels are now keys)

For task-modal component:
1. Add TranslocoPipe to task-modal.ts imports array
2. In task-modal.html:
   - "Edit Task" / "New Task" heading → {{ (isEditing ? 'TASK_MODAL_EDIT_TITLE' : 'TASK_MODAL_NEW_TITLE') | transloco }}
   - aria-label="Close dialog" → [attr.aria-label]="'TASK_MODAL_CLOSE' | transloco"
   - Replace all form labels, placeholders, and button text with corresponding TASK_ keys from en.json (executor must read the full task-modal.html to identify all strings)

For notification-toast component:
1. Add TranslocoPipe to notification-toast.ts imports array
2. In notification-toast.html:
   - aria-label="Dismiss notification" → [attr.aria-label]="'NOTIFICATION_DISMISS' | transloco"
</action>
