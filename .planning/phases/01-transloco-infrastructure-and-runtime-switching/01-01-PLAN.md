<objective>
Install @jsverse/transloco, create an HTTP-based translation loader that lazy-loads locale files, register the Transloco provider in app.config.ts, and create the en.json and de.json translation files with ALL keys for every hardcoded string in the application.

Purpose: Establishes the i18n runtime infrastructure so that components can consume translation keys via pipe/directive with lazy-loaded locale files and runtime switching.

Output: Working Transloco configuration, loader, and complete translation JSON files for EN and DE.
</objective>

<action>
Install @jsverse/transloco via pnpm: `pnpm add @jsverse/transloco`

Create src/app/transloco-loader.ts implementing TranslocoLoader interface:
- Injectable class TranslocoHttpLoader
- inject(HttpClient) using Angular inject() function
- getTranslation(lang: string) returns httpClient.get with path `/i18n/${lang}.json`
- The path /i18n/{lang}.json resolves from the public/ asset directory (already configured in angular.json assets glob)

Then register in src/app/app.config.ts:
- Import provideTransloco from @jsverse/transloco
- Import TranslocoHttpLoader from ./transloco-loader
- Add provideTransloco({ config: { availableLangs: ['en', 'de'], defaultLang: 'en', reRenderOnLangChange: true, prodMode: !isDevMode() }, loader: TranslocoHttpLoader }) to the providers array
- Import isDevMode from @angular/core
- Import provideHttpClient is already present (needed for HttpClient injection in loader)
</action>

- package.json contains "@jsverse/transloco" in dependencies
- src/app/transloco-loader.ts exists and exports class TranslocoHttpLoader
- TranslocoHttpLoader implements TranslocoLoader interface with getTranslation method
- src/app/app.config.ts contains provideTransloco in providers array
- provideTransloco config has defaultLang: 'en', availableLangs: ['en', 'de'], reRenderOnLangChange: true
- `pnpm build` completes without errors
</acceptance_criteria>
